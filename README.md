# InkSaver

InkSaver is a small Windows app that lives in the notification area (next to the
clock) and automatically prints one page every *X* days on the printer of your
choice. That way the cartridges of inkjet printers do not dry out, even if you go
weeks without printing anything.

## Features

- **Tray only**: everything is configured from the icon's menu (left or right click).
- **Configurable frequency**: every 1, 2, 3, 4, 5, 7, 10, 14, 21 or 30 days, or a
  custom value between 1 and 365 days.
- **Configurable printer**: the Windows default printer or any installed printer.
- **What to print**:
  - a *colour test page* generated by InkSaver (C, M, Y and K blocks, RGB mixes,
    gradients and a fine line pattern so every nozzle fires), or
  - the **first page of a PDF** of your choice.
  - *Preview…* shows exactly what will be printed.
- **Missed prints**: if the computer was off (or asleep) on the day a print was due,
  the page is printed the next time it starts, **2 minutes after startup** (to give
  the printer and network time to get ready). A notification is shown beforehand.
- **Print now**: prints immediately and restarts the day count.
- **Pause** automatic printing without closing the app (the icon turns grey).
- **Start with Windows** (enabled by default on first run; can be turned off from the
  menu). No administrator rights required.
- **History** of prints and errors (*Show history*).
- **Spanish** or **English** interface depending on the Windows language.
- If an automatic print fails (printer uninstalled, PDF deleted…) a notification is
  shown and it is retried every 30 minutes.

## How days are counted

Intervals are in **calendar days**: with a frequency of 3 days and a print on Monday,
the next one is due from Thursday at 00:00. If the computer is off that day, it prints
as soon as it is turned on again. Until the first print, the count starts on the day
InkSaver was first run.

## Installation

1. Download `InkSaver.exe` from *Releases* (or from the `InkSaver-win-x64` artifact of
   the latest *Actions* run).
2. Put it in a permanent folder, for example `%LOCALAPPDATA%\InkSaver\`.
3. Run it. An ink drop appears in the notification area (it may be hidden behind the ^
   arrow; you can drag it onto the taskbar).

It is a single self-contained executable: .NET does not need to be installed. It
requires Windows 10 (1809) or later, or Windows 11.

If you move the `.exe` to another folder, run it again from the new location and the
start with Windows entry updates itself.

### Uninstall

Uncheck *Start with Windows*, click *Exit* and delete the `.exe` and the
`%APPDATA%\InkSaver` folder.

## Where data is stored

`%APPDATA%\InkSaver\`

- `settings.json`: settings and the date of the last print.
- `inksaver.log`: history.

Start with Windows is registered under
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` (value `InkSaver`).

## Building

You need the .NET 8 SDK.

```bash
# Tests
dotnet test InkSaver.sln

# Single Windows x64 executable -> src/InkSaver/bin/publish/win-x64/InkSaver.exe
dotnet publish src/InkSaver/InkSaver.csproj -p:PublishProfile=win-x64
```

The project also builds on Linux/macOS (`EnableWindowsTargeting`), but the app and the
`tests/InkSaver.Tests` project only run on Windows; on those systems use
`dotnet test tests/InkSaver.Core.Tests`.

Every push is built and tested on GitHub Actions; pushing a `v*` tag (for example
`v1.0.0`) creates a release with the `.exe` attached.

### Project layout

| Path | Contents |
| --- | --- |
| `src/InkSaver.Core` | Settings (`AppSettings`, `SettingsStore`) and scheduling rules (`Schedule`). No Windows dependencies. |
| `src/InkSaver` | WinForms app: tray icon and menu, printing, test page, PDF rendering (Windows' built-in PDF engine, `Windows.Data.Pdf`), start with Windows. |
| `tests/InkSaver.Core.Tests` | Cross-platform tests for the logic. |
| `tests/InkSaver.Tests` | Tests that require Windows (GDI+, PDF). |
| `tools/make_icons.py` | Generates the icons (`python tools/make_icons.py`, requires Pillow). |
